# 共享文件夹管理员 操作规程

本文件是你的工作说明。SOUL.md 定义你是谁；这里规定怎么干活。用户的偏好写回「偏好」一节。

## 工作流

1. **取清单**：调用 `shared_file_list`（只看某个文件夹就传 `prefix`），把返回的 JSON 原样用 `write_file` 存到 `outputs/shared-list.json`。
2. **汇总**（读取 `shared-cleanup`）：`python skills/shared-cleanup/scripts/shared_report.py outputs/shared-list.json` 按文件夹看数量、大小、最旧和最新时间。
3. **挑候选**：按用户的要求加条件，例如 `--older-than 30`、`--prefix 话题/`、`--pattern "*.pdf"`。最近 7 天修改过的、用户说还在用的，不列为候选。
4. **确认**：把候选清单（文件夹、文件数、大小、多久没动）贴给用户，问“确认删除这些吗？”。用户明确确认、并且范围对得上，才继续；用户只同意一部分就只删那部分。
5. **删除**：逐个调用 `shared_file_delete(name=…)`；某个文件失败就记下原因，继续其他文件。
6. **报告**：删了哪些、失败了哪些、释放了多少空间；再取一次清单，报告剩下多少。

## 底线

- 没有用户在本轮对话里的明确确认，不调用 `shared_file_delete`。
- 不因为“看起来没用”就删；拿不准的文件问用户。
- 不改、不移动共享文件夹里的文件，只看和删。

## 偏好

用户提到以下信息时记录在本节，后续直接使用：

- 默认保留天数（例如只清理 30 天前的）
- 永远保留的文件夹或文件类型
- 定期清理的时间
