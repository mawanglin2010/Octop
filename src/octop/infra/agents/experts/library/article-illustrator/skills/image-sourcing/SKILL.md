# 找图与生图

> `references/` 路径相对于本技能目录。

## 1. 配几张、放哪里

- **封面 1 张**：公众号封面横版约 2.35:1（如 900×383），分享到朋友圈时还会裁成 1:1，主体放在中间；
- **正文 2–4 张**：放在小标题后，或长段落之间；1000 字左右配 2–3 张就够；
- 每张图要回答“读者看到它能多理解一点什么”：场景、对象、示意、氛围。数据和流程用图表或示意图，不要用无关的氛围图；
- 不要连续两段都放图，也不要放在引语和它的出处之间。

## 2. 先搜还是先生成

| 情况 | 选择 |
|------|------|
| 文章讲的是具体的机构、产品、地点、事件 | 先搜官方发布的图（新闻发布会、官网新闻稿、产品页的媒体素材） |
| 概念、趋势、观点、情绪类内容 | 直接生成插画或示意图 |
| 搜到的图授权说不清 | 不用，改为生成 |
| 涉及真实人物 | 只用官方发布、明确允许使用的照片；不生成真实人物 |

## 3. 能用的图和授权

授权判断细则见 `references/licenses.md`。简单说：

- **能用**：官方机构和企业新闻稿里注明可转载或用于报道的图；维基共享资源（Wikimedia Commons）上标了 CC0、CC BY、CC BY-SA、公有领域的图（按要求署名，BY-SA 注意相同方式共享）；Unsplash、Pexels、Pixabay 等免费图库的图（遵守其许可，仍然写署名）；用户自己提供的图；
- **不用**：新闻图片社（新华社、视觉中国、Getty、IC 等）的图；别的公众号、自媒体、社交平台上的图；搜索结果缩略图；带水印的图；看不到授权说明的图；
- 登记时“授权”写你在来源页上看到的原话或协议名，“署名”写作者或机构，“来源页”写能看到授权说明的那一页；
- 不去水印、不裁掉署名、不拼接别人的图。

## 4. 生图

调用 `generate_image`，提示词写清楚：

1. **主体**：画什么（充电桩、街道、商户、手机界面……）；
2. **风格**：扁平插画 / 写实摄影风 / 3D / 水彩 / 线稿，与账号偏好一致，同一篇文章的图风格统一；
3. **构图和比例**：封面写“横版宽幅构图，主体居中，左右留白”，正文写“横版 16:9”或“竖版 3:4”；
4. **色调**：和排版主题呼应（绿 / 蓝 / 橙）；
5. **不要的东西**：在提示词里写“画面中不出现任何文字、标志和水印”。生图模型写中文常出错，标题文字放在排版里，不要让模型画。

边界：

- 新闻、时政、灾害、事故类话题，用插画、示意或抽象风格，**不生成看起来像现场照片的图**；
- 不生成真实人物、公众人物的肖像，不生成商标、国徽、机构标识；
- 生成的图在图注里自动标“（AI 生成）”（按《人工智能生成合成内容标识办法》需要显式标识），不要删；
- 生图按张计费：一个位置最多重试两次，先改提示词再重试；用户给了预算就按预算来。

生成后用 `read_file` 看一下画面：有乱码文字、畸形的手和脸、和图注不符时重新生成或换位置。拿到的路径交给 `figure-pack` 的 `figures.py add` 登记（封面加 `--crop 2.35:1`）。

## 5. 图注

- 一句话描述画面，不超过 30 字；
- 不写初稿里没有的事实、数字、人名；
- 搜索来的图，署名和授权放在文末“图片来源”，图注里不用重复。
