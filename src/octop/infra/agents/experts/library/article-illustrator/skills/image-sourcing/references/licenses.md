# 图片授权速查

以下是判断“这张图能不能放进公众号文章”的常见情形。拿不准就不用，改为生成。本表不是法律意见，商业推广内容建议由用户确认。

| 来源 | 能否使用 | 登记“授权”怎么写 | 注意 |
|------|----------|------------------|------|
| 政府机构、企业官网新闻稿配图 | 新闻稿注明“欢迎转载”“可用于报道”时可以 | 官方发布，允许转载（附原话） | 只用于相关报道，不改动画面，署名机构 |
| 企业媒体中心 / Press Kit | 可以，按其说明 | 媒体素材，限报道使用 | 有的禁止商业用途 |
| 维基共享资源 CC0 / 公有领域 | 可以 | CC0 / 公有领域 | 仍写来源页 |
| 维基共享资源 CC BY / CC BY-SA | 可以，必须署名 | CC BY 4.0 / CC BY-SA 4.0（按页面所写版本） | 署名写作者；BY-SA 改动后需同样协议 |
| Unsplash / Pexels / Pixabay | 可以，遵守各自许可 | Unsplash License / Pexels License / Pixabay Content License | 不能把图当成“可识别人物的代言”；仍写署名 |
| 用户自己提供的图 | 可以 | 用户提供 | 让用户确认有权使用 |
| 新闻图片社（新华社、中新社、视觉中国、Getty、IC、Reuters、AP 等） | 不可以 | — | 需付费授权 |
| 其他公众号、自媒体、微博、小红书、抖音截图 | 不可以 | — | 著作权属于作者 |
| 搜索引擎图片结果、缩略图 | 不可以直接用 | — | 要找到原始来源页再判断 |
| 带水印、来源不明、授权页打不开 | 不可以 | — | 改为生成 |
| CC BY-NC（非商业） | 商业推广文章不可以，普通资讯谨慎 | CC BY-NC 4.0 | 让用户判断账号是否属于商业用途 |
| CC BY-ND（禁止演绎） | 可以原样使用，不能裁剪 | CC BY-ND 4.0 | 不要加 `--crop` |

生成的图：登记时方式写“生成”，写明提示词和模型；图注自动带“（AI 生成）”。
